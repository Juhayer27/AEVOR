# AEVOR
Open index.html via any static host (Netlify, GitHub Pages, Cloudflare Pages, Vercel). Service worker/PWA needs https.
- Products: js/products.js  (id, name, brand, price|null, gender, type, strap, movement, style, affiliate link, image, water resistance)
- Styles: css/style.css  - Logic: js/app.js
- Replace https://your-domain.com in index.html, robots.txt and sitemap.xml with your real domain.
